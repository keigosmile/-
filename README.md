# ここは何藩？（ブラウザ試作版）

現在地（または地図上でタップした地点）が、**慶応4年1月1日（1868年1月25日）時点**でどの旧国・どの藩の領地だったかを表示する、1ページのWebアプリです。
天領・旗本領・寺社領なども、藩と同じ並びで表示します。

- 旧国名（例：武蔵国）と Wikipedia へのリンク
- 藩名（推定）と Wikipedia へのリンク、CODH 藩ID へのリンク
- 藩主名（幕末時点・推定）と Wikipedia へのリンク
- 地図上で藩の領域を色分けして表示（選んだ藩は太線で強調）
- 出典ページ：[credits.html](credits.html)

## 動かし方

サーバーで配信するだけで動きます（ビルド不要）。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

iPhone の Safari で「現在地」を使うには **https** で配信する必要があります（GitHub Pages など）。

## データ

### 1. 藩などの領域：幕末期近世村領域データ（02_kyudaka_v2.01）

- 出典：<https://github.com/yaoyue00085856/Kyudaka_agrivillage>（本田謙一氏）
- ライセンス：CC BY-SA 4.0
- 中身：**CSV（Shift_JIS）のみで、ポリゴンの形は含まれていません。**
  - `01_Village_point_data_v2.csv`：近世村 66,581件の点（経緯度、国・郡・村名、領分1〜6）
  - `02_Village_polygon_field_v2.csv`：領域単位（AID）59,808件の属性（国・郡・村名、領分1〜8。石高の大きい順）
  - `03_KEY_AID.csv`：農林水産省「農業集落境界データ（2015年）」の KEY（139,786件）と AID の対応
- 形は、農林水産省の **農業集落境界データ（2015年農林業センサス、Shapefile）** と KEY で結合して作ります。
  北海道・沖縄は対象外。
- 注意：上位 README は「慶応4年1月1日時点」、`02_kyudaka_v2.01/README.md` は「慶応3年1月1日時点」と書かれています（データ説明PDFは慶応4年1月1日）。
  本アプリは PDF と上位 README に従い「慶応4年1月1日」としています。
- 国名は明治元年12月の分割後（岩代・磐城・陸前・陸中・陸奥・羽前・羽後）で記録されています。アプリでは陸奥国・出羽国として表示し、分割後の国名を補足します。

### 2. 領域の形：農業集落境界データ（2015年）

- 出典：農林水産省「地域の農業を見て・知って・活かすDB」<https://www.maff.go.jp/j/tokei/census/shuraku_data/2015/ma/index.html>
- 利用条件：複製・加工自由。出典の明示と、加工した場合は編集・加工者の明示が必要。
- 取得したのは北海道・沖縄以外の45府県分（ZIP合計 約255MB、展開後 約434MB、139,790ポリゴン）。

### 3. 藩ID：CODH 藩IDデータセット

- 出典：<https://codh.rois.ac.jp/han/>（`han-20250919.csv`、408藩。列：藩ID, 藩名, 別名, 国・地域ID, 注目スコア, 補足説明）
- ライセンス：CC BY 4.0（doi:10.20676/00000465）
- 領分名（例：「信濃松代藩」）と藩ID（H185）の対応は、CODH「幕末期近世村領域データセット」の[藩一覧](https://geoshape.ex.nii.ac.jp/av/han/)の各ページから取得（CC BY-SA 4.0）。
  元データの領分 286種類のうち 279種類はこれで対応し、残り7種類（上総飯野藩・伊予吉田藩・信濃須坂藩・常陸下舘藩・美作勝山藩・讃岐多度津藩・陸奥湯長谷藩）は藩IDデータセットの藩名から手で対応付けました。
  藩以外の領分（幕領・旗本領分・社寺領・一橋家領分・田安家領分・公家領・皇室領・宮家領・交代寄合○○家 など）は18種類です。

### 4. 旧国の境界

次の候補を調べました。

| 候補 | ライセンス | 採否 |
| --- | --- | --- |
| **幕末期近世村領域データの国名で、集落境界を国ごとにまとめる** | CC BY-SA 4.0（藩の領域と同じ） | **採用** |
| CODH「[旧国・旧郡境界データセット](https://geoshape.ex.nii.ac.jp/kg/)」（人間文化研究機構「幕末明治地勢地図境界データ」を加工） | **CC BY-NC 4.0（非営利のみ）** | 不採用（将来アプリとして配布・収益化する場合に使えないため） |

採用した方法は藩の領域と同じ元データから作るので、旧国境界と藩の領域がぴったり重なり、ライセンスも1種類で済みます。
ただし旧国の境界も2015年の農業集落境界に沿った近似になります。

### 5. 藩主名

- Wikipedia日本語版の各藩記事の「歴代藩主」節から、慶応4年1月1日に在任していた人を自動で推定しました。
  - 在任年が書かれている一覧（60藩）はその年で判定。
  - 在任年がない一覧（167藩）は、最後の3代の藩主記事から家督相続の年を読み取って判定。
  - 記事が見つからない・判定できない藩（35藩）と、自動判定を目視で確認して誤っていた藩は `tools/manual.json` で手作業補正（藩主 53件、記事名 23件）。
- 268の「藩」領分のうち 266 に藩主名があります（常陸宍戸藩は元治元年に改易中、陸奥白河藩は無主のため注記のみ）。
- **推定であり誤りを含む可能性があります。** アプリ内でも「推定」と表示しています。

### 加工後のサイズ

| ファイル | サイズ | gzip後 |
| --- | --- | --- |
| `data/ryobun.topojson` | 2.42 MB | 0.74 MB |
| `data/han.json` | 57 KB | 10 KB |

- 集落ポリゴン 139,790件 → 「旧国＋領主の組み合わせ（相給を含む）」ごとに統合して **2,841件**（元の結合済みShapefile 約180MB）
- 境界を mapshaper で簡略化（Visvalingam、頂点の0.6%を保持、0.05km²未満の小片を除去）、TopoJSON（座標量子化 1e5）で出力
- 旧国レイヤー（68か国）は同じ TopoJSON 内に入れて境界線を共有
- GitHub Pages は gzip で配信するため、実際の転送量は約0.75MBです
